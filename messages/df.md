# summary

Run Deltaforce.

# description

Run the root Deltaforce command (`sf df`).

# flags.name.summary

Name to include in the Deltaforce output.

# flags.name.description

Optional label used by Deltaforce.

# examples

- Run the df command:

  <%= config.bin %> <%= command.id %>

- Run with a custom name:

  <%= config.bin %> <%= command.id %> --name Deltaforce

# info.df

Deltaforce command for %s at %s.
